### 合规边界（关键，决定全站措辞）

- UAE 2021 Penal Code 第 460 条：赌博 = 各方约定**输者向赢者支付钱款或其他利益**。无赌注的社交/策略麻将不属于赌博。
- 但第 461/462 条对参与者与组织者处罚很重；**赌资、筹码计钱、win money、bet、jackpot 是绝对禁区**。
- Harper's Bazaar 明确记录当地存在「金钱往来」污名 → 页面必须**主动去赌博化**，把「无赌注社交」写成明确定位，而不是回避。

## 二、竞争格局：空窗在哪

| 端 | 现状 | 空窗 |
|---|---|---|
| 中国定制工厂（LYNgames / Malada / SO MAHJ / Kaile） | **全部面向北美 NMJL 美式**（152–160 张、Joker、年度 NMJL 卡） | 无人做中式 144 张 + 阿语 + 迪拜变体 + GCC 合规 |
| GCC 零售端（Ubuy / dubizzle / emarkiz） | 跨境直邮、二手转让、杂货电商 | 无权威选购/教学/定制内容页 |
| 阿语教学（搜「طريقة لعب الماجونج」「قواعد الماهجونج」） | 结果**全是英文站**（WikiHow、MahjongPeak 等） | **阿语教学内容基本为零** |
| 海湾 B2B（咖啡馆 / 俱乐部 / 礼赠） | 已在自发组局、自制教学卡 | 无人提供「双语教具 + 定制套装 + 批量供货」的采购内容 |

**结论：机会不在「卖麻将」，而在「谁能帮海湾买家定制一套带阿语教学的麻将」。这个词组目前几乎无人占位。**
