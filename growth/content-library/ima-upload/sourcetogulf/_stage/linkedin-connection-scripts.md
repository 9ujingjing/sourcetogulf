# LinkedIn 加人备注怎么写（可直接复制）

## 三条原则（决定了接受率）
1. **前 15 个字符最关键**——手机上对方只看到开头，第一句必须有"我为什么找你"的具体信息，不能是套话。
2. **提一个具体细节**（对方的城市 / 公司 / 刚发的帖子 / 做的品类），接受率能翻 2–3 倍。
3. **不推销**。第一句话绝不能是"我想帮你从中国采购"——那是被拒最快的写法。定位成"同行交流 / 备用资源"。

## 模板 A · 海湾小卖家 / 电商卖家（Salla / Zid / IG 小店老板）
```
Hi [Name], I work with small brands in the Gulf on sourcing from China — mostly helping first-time importers figure out MOQs and landed cost before they commit. Saw what you're building at [X]. Happy to share what I'm seeing on the factory side if it's ever useful. — Robin
```

## 模板 B · 采购 / Supply Chain 从业者
```
Hi [Name], I'm on the China side of Gulf–China sourcing — factories, QC, shipment consolidation. Always useful to know people who actually run procurement in [Dubai/Riyadh]. Not selling anything, just comparing notes on lead times and supplier vetting. — Robin
```

## 模板 C · 创业者 / 想做自有品牌的人
```
Hi [Name], I help small Gulf brands put their own label on products made in China — sampling, packaging, low MOQ. If private label is on your roadmap at any point, happy to be a resource. Following what you're doing at [X]. — Robin
```

## 模板 D · 通用版（批量加人时用，无需个性化）
```
Hi [Name], I'm Robin — based between Guangzhou and Dubai, working on China→Gulf sourcing for small brands. Always good to connect with people building things in the region. Happy to compare notes anytime. — Robin
```

## 发送节奏与红线
- 每天 **15–20 个**即可，不要一次群发几十个。
- 🔴 **被点了太多 "I don't know this person" 会被 LinkedIn 限流甚至限制邀请功能**。宁可少加、加准。
- 🔴 对方接受后 **不要立刻甩广告 / 报价 / 链接**。等 1–2 天，或先正常回一句。上来就推销 = 被解除连接或被举报。
- ✅ 对方接受后的第一句可以是：`Thanks for connecting — if you ever need a sanity check on a China quote, just message me. No pitch.`
- 优先加：海湾本地小卖家、电商运营、采购/供应链、零售创业者。
- ❌ 不加：同行 sourcing agent / 货代（加了没用，还可能抄打法）。

## 为什么这步比发帖重要
账号连接数太少时，LinkedIn 算法没有分发对象，发帖展示量会极低（实测首帖仅 15 展示）。先把连接数拉到 150+，发帖才有意义。
