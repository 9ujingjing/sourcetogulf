## 一、最常用：让库自己长出内容（每周发一次就够）

```
扫我的 SourceToGulf 内容沉淀库，跑 scan_library.py，从本周内容机会里挑 2 条最值得做的，
按我的风格写成可直接发的 TikTok + LinkedIn 文案。
```

> 我的风格（已固化，不用每次重复）：**标题给 5 个让我选 · 配文 3–5 句别写小作文 · 加拿大光头式吐槽 > 正经纪实 · 钩子 = 具体场景 + 反差 + 利他 + 互动**。
> 只要"标题+配文+标签"时，**不要**附带拍摄脚本。

## 二、新询盘来了：找历史案例 + 要话术

```
刚收到一个询盘：[把客户原话或需求贴这里]。
去我的内容库（尤其 assets/ 素材资产库里的 10 个真实素材和阿语话术）找最像的历史案例，给我：
①判断这是不是好询盘（标准品 / 要不要开模 / 有无认证门槛）
②英文 + 阿拉伯语回复话术（极简版，别写长）
③合规风险提醒（ECAS / SFDA / SABER / 危险品）
```

## 三、倒料：把真实业务沉淀进库（每天 30 秒）

```
把这段真实业务动作沉淀进我的内容库：[粘贴 WhatsApp 对话 / 报价 / 打样反馈]。
按 _template.md 的 frontmatter 格式写到对应子目录，客户必须匿名、报价用区间，
然后跑 scan_library.py 告诉我新增了哪些内容机会。
```

> 嫌麻烦就直接往 `inbox.md` 里原样粘贴，周一自动化会帮你整理成结构化条目。

## 四、算价：用库里的真实成本模型

```
用我内容库里的真实报价与成本模型（约旦 59→136 第纳尔利润账、ZYVO 加价率、
cainiao 运费公式、AED/QAR/SAR 落地价口径），帮我给这个客户算落地价区间：[需求/数量/目的地]。
往高报不往低报。
```

## 五、找选题：只想知道这周写什么

扫我的内容库，给我本周 3 个最值得写的选题，每条注明：
来自哪个真实案例、可发哪些平台、站内能内链哪个页面。按 ROI 排序。
```

```

## 铁律（我每次都会自动遵守，你不用提醒）

1. **客户真名 / 手机号 / 头像 / 社交账号**永不进公开内容，一律 `anon_name` 匿名。
2. 报价对外**只用区间**，不露具体成本。
3. `/quote/` 下的 noindex 内部页面原文**不外流**（只提炼脱敏角度）。
4. **仿牌（counterfeit）案例禁止做公开社媒**，只作内部筛选参考。
5. 合规门槛先算：ECAS（阿联酋）、SFDA / SABER（沙特）、危险品 UN 编号——不划算就明说放弃。
