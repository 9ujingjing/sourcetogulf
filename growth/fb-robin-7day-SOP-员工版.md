# Robin 号 7 天执行手册（员工版 · 无需懂英文）

> 使用说明：本手册全部中文。凡是灰底代码框里的英文，**不用看懂，直接复制粘贴**即可。
> 每天做完，填最后一页的「每日记录表」，发给负责人。

---

# 第 0 天：开工前准备（只做一次，约 20 分钟）

## 0-1 把 Facebook 界面改成中文（重要，不然全是英文看不懂）

1. 打开 Facebook，点**右上角圆形头像**
2. 点「**Settings & privacy**」（中文版叫「设置和隐私」）
3. 点「**Language**」（语言）
4. 选「**简体中文**」→ 保存
5. 页面刷新后按钮全变中文 = 成功 ✅

## 0-2 固定登录环境（防封号）

- 只用**同一台电脑、同一个 Chrome 窗口**登录这个号。
- 手机上也登录了？可以，但**不要频繁在电脑/手机之间来回切**。
- 不要用别人的网络、不要在网吧登录。

## 0-3 准备一个记录表

新建一个 Excel 或记事本，抄下最后一页的表格标题，每天填。

## 0-4 检查资料页填完了

打开自己主页，确认这几栏有内容（没有就找负责人要）：
- 姓名、简介、工作单位、居住城市、头像、封面图

**第 0 天做完，截图发负责人确认，再开始第 1 天。**

# 第 1 天：加 3 个群 + 加 15 个好友

## 步骤 1：搜群并申请加入（做 3 次）

1. 点 Facebook 顶部**搜索框**（放大镜🔍）
2. **复制**下面第一个英文词，粘进搜索框，按回车：

```
UAE Buy and Sell
```

3. 搜索结果页面上方有一排筛选：点「**小组**」（英文 Groups）
4. 结果里挑一个，**要满足这 2 条**：
   - 成员数字 **大于 5 万**（看群名下方写的 members / 成员）
   - 群名里有 UAE / Dubai / Gulf 字样
5. 点进去，点蓝色按钮「**加入小组**」（Join Group）
6. 如果弹出问题要回答（英文），**复制下面这段填进去**：

```
I work with suppliers in China and connect with Gulf resellers. I will follow the group rules.
```

7. 显示「**待审核 / Pending**」= 成功 ✅（管理员批准要几小时到 2 天，正常）

**重复以上步骤，把下面 2 个词也搜一遍、各加 1 个群：**

```
Dubai Buy and Sell
```

```
Abu Dhabi Buy and Sell
```

⚠️ **今天只加 3 个群，不要多加**。加太多会被 FB 判异常。

## 步骤 2：加 15 个好友

1. 在刚才那 3 个群里，随便点进一个（哪个批准了就用哪个；都没批准就用搜索）
2. 看群里**最近发帖的人**（有头像、有真实照片的），点他的名字进主页
3. **要满足这 2 条才加**：
   - 头像是**真人照片**（不是风景、不是商品图）
   - 主页有几条正常帖子（不是空号）
4. 点「**添加好友**」（Add Friend）
5. 如果有「**写个招呼语**」的输入框，**复制下面这段**：

```
Hi, I'm Robin — a China sourcing agent working with Gulf resellers. Happy to connect and share market finds.
```

6. 重复到**加满 15 个人**，然后停手

⚠️ **今天绝对不要**：不发任何帖子、不给人发私信、不在群里评论。今天只加群+加好友。

## 步骤 3：填记录表

在记录表里写：日期、加了哪 3 个群、加了几个好友。

| 复制这句英文 | （中文意思，不用发） |

| `Where did you get this?` | 你在哪买的 |
| `Great quality 👌` | 质量挺好 |
| `This is useful, thanks for sharing` | 挺有用，谢谢分享 |
| `Interested, is it still available?` | 有兴趣，还有货吗 |
| `Good price 🔥` | 价格不错 |
| `I like this design` | 我喜欢这个设计 |
| `Very practical 👏` | 很实用 |
| `Thanks for the info 🙏` | 谢谢信息 |

⚠️ **不要在评论里写我们的网址、WhatsApp、公司名**。今天只是让账号看起来像真人。

# 第 4 天：发第 1 条帖子（不是卖货，是"日常"）

## 步骤 1：准备图片

要一张**广州批发市场 / 仓库 / 货架的实拍照片**（手机拍的最好，不要网上下载的精修图）。
没有？找负责人要。

## 步骤 2：发帖

1. 打开自己主页，点「**你在想什么？**」（写帖子的框）
2. **复制**下面全部内容粘进去：

```
Sourcing day in Guangzhou 🇨🇳
Every week I walk these markets looking for what Gulf buyers actually ask for.
This season it's cooling gadgets, car accessories and camping gear.
Ask me anything about buying from China.
#Dubai #UAE #Sourcing #China #GulfBusiness
```

3. 点相机图标，**上传步骤 1 那张照片**
4. 检查右上角是「**公开**」（地球图标）—— 如果是「仅好友」，点一下改成**公开**
5. 点「**发布**」

## 步骤 3：发布时间要对

**必须在北京时间 17:00–19:00 之间发**（这时候中东人正在上网）。
早了晚了都没人看。

## 步骤 4：有人评论就回

- 有人评论（英文看不懂没关系），**复制下面这句回**：

```
Thanks! DM me anytime 🙏
```

- 如果对方评论里有 **price / how much / cost** 这几个词（就是在问价），**不要自己回**，**截图发给负责人**。

# 常见问题（照着处理，别自己想办法）

| 情况 | 怎么做 |
|---|---|
| 加好友按钮点不了，提示 "You're temporarily blocked" | **立刻停止加人，当天不要再操作**，明天再加，数量减半 |
| 群申请一直不批准 | 正常，等着。别反复点、别退群重加 |
| 群管理员删了我的帖 | 不要再在那个群发，只评论。记下群名告诉负责人 |
| 收到英文私信 | **截图发负责人**，不要自己回 |
| 有人问价 | **截图发负责人**，不要自己报价 |
| FB 要求验证身份 / 上传证件 | **马上停手，截图发负责人**，不要自己上传 |
| 一天加了 15 个还想加 | **不要加**。超量是封号第一原因 |
