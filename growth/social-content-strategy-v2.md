## 1. 你的业务怎么套用（sourcing agent 适配）

你贴的案例里「PROJECT SENSE / 安装落地 / 完整资料包 / 按职位搜」全是**制造商卖货**视角。翻译成 agent 视角：

| 案例原意 | SourceToGulf 对应动作 |
|---|---|
| 拍安装落地效果 | 拍**工厂验货视频、样品打包、装柜发货、QC 细节** |
| 发完整 PDF 资料 | WhatsApp 发「产品图+尺寸颜色+验货报告+包装方案+交期」六件套 |
| 按职位搜客户 | LinkedIn 搜 `procurement / contractor / project manager / interior buyer / salon owner / purchasing manager`，看项目再触达 |
| 展示解决方案不是产品 | 发「我们怎么帮客户解决一个具体采购难题」，不发了「我们牛」 |

**你的差异化资产 =「我是中国工厂旁边的那双眼睛」**。所有内容围绕这个点，比任何产品图都有说服力。

## 2. 内容四大主题（LinkedIn / 时间线主力）

每类给：目的 + agent 适配思路 + 示例标题（英文，可直接发）+ AI 生成 prompt。

### 主题一：行业趋势 & 客户需求
- **目的**：吸引有采购计划、对行业敏感的 Gulf 买家。
- **思路**：不是科普，是「解读客户所在行业的机会与痛点」。
- **示例标题**：
  - `Why modest-wear demand spikes in KSA 6 weeks before Ramadan`
  - `3 sourcing shifts Gulf retailers should watch in 2026`
  - `Why more Dubai resellers are moving from Alibaba spot-buy to a China partner`
- **AI prompt**：
  ```
  你是有12年中东经验的 China sourcing agent。写一条 LinkedIn 英文帖，主题：[填入趋势，如 KSA modest wear 旺季]。
  结构：1句钩子 → 解读客户所在行业的 2-3 个变化/痛点 → 用数据或场景带出共鸣 → 结尾温和 CTA（connect/DM）。
  语气像行内人聊天，不用绝对词（最/第一），120-180词。
  ```

### 主题二：客户故事 & 场景化需求
- **目的**：让客户代入「这就是我」，激发兴趣。
- **思路**：匿名化真实订单——某 Dubai 卖家如何靠低 MOQ 起步、某 Riyadh 店如何避掉 MOQ 陷阱。
- **示例标题**：
  - `How we helped a Riyadh abaya shop source fabric at 20-pc MOQ`
  - `How a Dubai car-accessory reseller cut delivery time by 40%`
- **AI prompt**：
  ```
  写一条 LinkedIn 英文帖，讲一个匿名客户故事：客户画像=[如 Dubai 小卖家]，痛点=[如起订量太高]，
  我们怎么做=[如找义乌小单工厂+视频验货]，结果=[具体数字/前后对比]。
  用「How we helped…」开头，具体、有数字，结尾 CTA。不用绝对词，130-180词。
  ```

### 主题三：产品差异化 & 技术亮点
- **agent 适配**：你没产品，你的「技术」是**验货标准 / QC 细节**。
- **示例标题**：
  - `3 stitching details that separate a good abaya from a cheap one`
  - `What we check in a factory before approving your order`
- **AI prompt**：
  ```
  写一条英文帖，主题=[如 abaya 走线怎么看质量]。结构：钩子 → 列 2-3 个具体可看的细节 → 说明为什么重要。
  语气专业克制、无销售话术，像老买手在带新人。120-160词。
  ```

### 主题四：供应链知识 & 采购避坑（最易传播、最建立专家感）
- **目的**：零销售压力地建立信任，最容易被收藏转发。
- **示例标题**：
  - `5 mistakes Gulf buyers make when sourcing from China`
  - `UAE customs: what actually gets stuck (and how to avoid it)`
  - `How to read a Chinese supplier quote without getting burned`
- **AI prompt**：
  ```
  写一条 LinkedIn 英文帖，主题=[采购避坑点，如 MOQ 陷阱]。结构：钩子 → 列 3 个具体错误+每个一句怎么避 → 温和 CTA。
  像在帮同行排雷，不用绝对词，130-180词。
  ```

## 4. 「拍过程不拍产品」拍摄清单

每条内容至少含 1 个真实画面（手机拍即可，比网图强 10 倍）：

- ✅ 工厂车间 / 批发市场实拍（人在场，侧脸或背影）
- ✅ 验货近景：量尺寸、看走线、测功能
- ✅ 样品箱打包、贴标、写地址
- ✅ 装柜 / 发货瞬间
- ✅ 白板排期、WhatsApp 对话（客户名打码）
- ✅ 「下单前和工厂视频通话」截图感
- ❌ 空办公室摆拍、网图、logo 墙特写

**多图轮播（2-4 张）曝光 > 单图。**

## 5. LinkedIn 主动开发 SOP（按职位搜，不群发）

1. 搜索框输入职位 + 地区：`procurement UAE` / `interior buyer Dubai` / `salon owner Riyadh` / `purchasing manager KSA`
2. 看对方**最近动态**：谁在发新项目、谁在找供应商、谁关注酒店/公寓/商业空间
3. 先**点赞/评论**其项目帖（有价值评论，不广告）
4. 再发 **Connect**，附 personalized 小纸条（引用他刚发的项目）
5. 通过后才私信，发**主题四的避坑内容**或一句「我们在广州，可帮你验货」——绝不秒发产品册

> 红线：不买粉、不群发、不换号、不秒广告。

| 账号 | 保留/新增 | 备注 |
